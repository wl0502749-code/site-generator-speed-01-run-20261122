A faster drop-in for makefun-site 1.0.0: `solve.js` returns, byte for byte, the output tree makefun-site 1.0.0's `build` returns for the same input — same front matter, template dialect, Markdown subset, slug rule and report — in about a third of the CPU time. `main.ts` is the harness driver: it reads every case from `/input/cases.json`, answers each with `run`, and writes `/output/answers.json`.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
